# On-demand requests

In your **private working repository**, create or update `generate.json`:

```json
{"notionPageId":"11111111-1111-4111-8111-111111111111","requestId":"example-package-v1"}
```

Replace the fictional UUID with your own application **page** UUID. Change requestId to trigger another push. This pointer contains no application prose or credentials. This public source deliberately includes no active request.

Alternatively, use **Actions → Generate Notion application package → Run workflow** and enter the page UUID. See [setup and phone instructions](../NOTION_WORKFLOW.md).
